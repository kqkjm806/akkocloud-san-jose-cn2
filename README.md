## 线路实测：150ms 和 6MB/s 是怎么来的

AkkoCloud 圣何塞的线路结构是回程三网 CN2 GIA，去程电信走 CN2 GIA、联通走 CN2 GIA、移动直连。官方页面写的是“三网回程 CN2 GIA 电信去程 CN2 GIA”，测评者补充了联通去程也走 GIA、移动直连。别把“三网回程 GIA”理解成三网去程全都优化过，移动方向是直连，没有 GIA。

第三方测评给出的数据：本地 Ping 圣何塞节点稳定在 150ms 左右；非高峰时段文件下载约 6MB/s，折算 48Mbps 上下；晚高峰掉到 3 至 4MB/s，约 24 到 32Mbps，测评者称看 1080p 视频没压力。

这组数字和套餐标称的 500Mbps、1000Mbps 差了一个数量级，原因不在虚标。端口速率是机房侧的上限，国内实际下载速度受国际出口带宽、本地宽带、跨境拥塞共同限制，任何美国 VPS 从国内单线程拉文件都跑不到端口标称值。买之前按“国内实际 3 到 6MB/s”做预期，比按“500M 带宽”做预期靠谱得多。

还要说明，150ms 和 6MB/s 来自单个测评者的本地网络，属于单点样本。电信、联通、移动三家到圣何塞的路由不同，你所在省份的出口也不同，实际结果可能上下浮动几十毫秒。官方提供 Looking Glass 测试地址 sjclg.akkocloud.com，下单前先 Ping 一遍，再下载一个测试文件，比看任何测评都直接。法兰克福是 fralg.akkocloud.com，伦敦是 lonlg.akkocloud.com，这家还有德国和英国节点，本文只讨论美国圣何塞。

## 500GB 双向流量，实际能用的有多少

AkkoCloud 的流量按双向计费，入站加出站合并计算。500GB 双向意味着上传和下载加在一起不能超过 500GB，不是各 500GB。

按月折算，500GB 大约相当于每天 16GB 的上下行总量。这是个编辑换算，不是商家承诺。个人博客、企业展示站、SSH 隧道、轻量中转，这个量级基本用不完。图片站、软件下载、视频转码这类出站吃流量的业务，几天就能打满。

资料里没有给出超流量之后的计费单价或限速规则。如果你的业务有可能接近上限，下单前问清楚超量怎么处理，是限速、停机还是按量计费，别等账单出来才发现。

## IP 段：38 段和 185 段不是一回事

圣何塞机房分配两种 IP。38 段是原生 IP，可以直接解锁 Netflix、Disney+ 等流媒体；185 段不是原生 IP，商家配了 DNS 解锁，测评者的说法是实际效果差不多。同一款套餐可能分到其中任意一种，不由你选。

介意原生 IP 的读者，这条信息比价格更重要。官网购物车页面自己也写明了：Looking Glass 的测试 IP 只是测试地址，不代表分配给你的就是这个段，也不保证是原生 IP，并且明确写了不接受以“不是原生 IP”为由申请退款。换句话说，下单前确认比事后申诉有用。可以先开工单问当前分配段，或者接受 DNS 解锁的方案再付钱。

一定要原生 IP 且不接受 DNS 解锁的，直接跳过。官网已经写明不保证原生，也不接受以此退款。
